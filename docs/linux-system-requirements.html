Bibirble for Linux: system requirements

Bibirble is a single program file. Every Bible version, the Story Mode map and its word list are built into it.

Computer

  • A 64-bit PC (x86-64). ARM computers such as the Raspberry Pi are not supported.
  • A desktop (X11 or Wayland) with a screen of at least 1024 x 768. The window can shrink to 420 x 420, but a game only shows every guess row and the Submit Answer button at about 420 x 850 (tall) or 900 x 620 (wide) and bigger.
  • About 50 MB of disk space (the program is 47 MB) and 256 MB of free memory (it uses about 160 to 170 MB while playing).

Linux version

It needs glibc 2.38 or newer and the C++ library from GCC 13 or newer, which these have:

  • Ubuntu 24.04 or newer
  • Linux Mint 22 or newer
  • Debian 13 (trixie) or newer
  • Fedora 39 or newer
  • Arch Linux, Manjaro and other up-to-date rolling releases

Older versions, such as Ubuntu 22.04 or Debian 12, can't run it.

Libraries to install

It uses wxWidgets 3.2 (GTK 3) and zlib. Install them once:

  • Ubuntu, Linux Mint, Debian: sudo apt install libwxgtk3.2-1t64 zlib1g
  • Fedora: sudo dnf install wxGTK zlib
  • Arch Linux, Manjaro: sudo pacman -S wxwidgets-gtk3 zlib

Running it

  1. Download Bibirble.
  2. Make it runnable: chmod +x Bibirble
  3. Start it: ./Bibirble

To add it to your app menu, copy bibirble.desktop from the source code to ~/.local/share/applications/ and set its Exec= line to where you saved Bibirble.

What these requirements come from

Worked out from the build itself (commit f827b76, pull request #20, built on Ubuntu 24.04 with GCC 13.3): the libraries it links to are wxWidgets 3.2 (core and base), zlib, libstdc++, libgcc and glibc; the newest symbol versions it uses are GLIBC_2.38 and GLIBCXX_3.4.32.

  • libwx_gtk3u_core-3.2.so.0 and libwx_baseu-3.2.so.0: wxWidgets 3.2 (libwxgtk3.2-1t64 on Ubuntu/Debian, wxGTK on Fedora, wxwidgets-gtk3 on Arch)
  • libz.so.1: zlib (zlib1g, zlib, zlib)
  • libstdc++.so.6, libgcc_s.so.1, libm.so.6, libc.so.6: part of every Linux system

Measured on this build

Run on a 4-core x86-64 machine with 16 GB of memory under a virtual X display (no window manager), five times. Pull request #20 only changes this page, so the program is the same as pull requests #17 to #19 (commit f2b80c6 onward). Start-up, start-screen memory and idle CPU were measured again; the other numbers carry over from that same program:

  • Program size: 49,147,528 bytes (about 47 MB), the same as before.
  • Time to the first window: about 1.9 seconds (1.88 to 2.20; the first, cold run was the slowest), most of it the loading screen, which itself appears within about 0.1 to 0.4 seconds.
  • Memory on the start screen: about 153 to 155 MB; in a game: about 159 MB; on the Story Mode map: about 158 MB.
  • CPU while sitting idle: almost none (0 to 1 hundredths of a second over 5 seconds, measured five times).
  • Window sizes in a game: 420 x 850 and 900 x 620 show everything. At 420 x 420 the number keys cover the guess rows and Submit Answer is hidden; at 421 x 420 (wide) the guess rows are squeezed to a sliver; at 420 x 600 and 800 x 560 the last rows and Submit Answer are cut off. Enter still submits a guess.
  • Story Mode tests (story_tests): all pass.
