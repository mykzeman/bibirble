Bibirble for Linux: system requirements

Bibirble is a single program file. Every Bible version, the Story Mode map and its word list are built into it.

Computer

  • A 64-bit PC (x86-64). ARM computers such as the Raspberry Pi are not supported.
  • A desktop with a screen (X11 or Wayland) at least 420 x 420 pixels.
  • About 50 MB of disk space and 256 MB of free memory.

Linux version

It needs glibc 2.38 or newer and the C++ library from GCC 13 or newer, which these have:

  • Ubuntu 24.04 or newer
  • Linux Mint 22 or newer
  • Debian 13 (trixie) or newer
  • Fedora 39 or newer
  • Arch Linux, Manjaro and other up-to-date rolling releases

Older versions, such as Ubuntu 22.04 or Debian 12, can't run it.

Libraries to install

It uses wxWidgets 3.2 (GTK 3) and zlib. Install them once:

  • Ubuntu, Linux Mint, Debian: sudo apt install libwxgtk3.2-1t64 zlib1g
  • Fedora: sudo dnf install wxGTK zlib
  • Arch Linux, Manjaro: sudo pacman -S wxwidgets-gtk3 zlib

Running it

  1. Download Bibirble.
  2. Make it runnable: chmod +x Bibirble
  3. Start it: ./Bibirble

To add it to your app menu, copy bibirble.desktop from the source code to ~/.local/share/applications/ and set its Exec= line to where you saved Bibirble.

What these requirements come from

Worked out from the build itself (version 6be33dd, built on Ubuntu 24.04): the libraries it links to are wxWidgets 3.2 (core and base), zlib, libstdc++, libgcc and glibc; the newest symbol versions it uses are GLIBC_2.38 and GLIBCXX_3.4.32.
