Installing Bibirble on Linux

Bibirble for Linux is one file called Bibirble. The Bible verses and the icon are built into it, so you don't need any data files next to it.

1. Check your Linux is new enough

You need a 64-bit (x86_64) Linux with glibc 2.38 or newer. That means roughly:

  • Ubuntu, Kubuntu, Xubuntu: 24.04 or newer
  • Linux Mint: 22 or newer
  • Pop!_OS: 24.04 or newer
  • Debian: 13 (trixie) or newer
  • Fedora: 39 or newer
  • Arch, Manjaro, EndeavourOS, openSUSE Tumbleweed: any current install

Not sure? Run this and check that the number is 2.38 or higher:

ldd --version | head -1

On an older system, build it from source instead (see the last section).

2. Install the libraries it needs

Bibirble has wxWidgets and the C++ runtime built in. It only needs GTK 3 and libSM from your system. Most desktops already have these, so this step usually just says "already installed".

Ubuntu, Mint, Pop!_OS, Debian:

sudo apt install libgtk-3-0 libsm6

Fedora:

sudo dnf install gtk3 libSM

Arch, Manjaro, EndeavourOS:

sudo pacman -S --needed gtk3 libsm

openSUSE:

sudo zypper install libgtk-3-0 libSM6

3. Unpack and run

From the folder where you downloaded Bibirble-Linux-x86_64.tar.gz:

tar xzf Bibirble-Linux-x86_64.tar.gz
./Bibirble/Bibirble

If it says "Permission denied", make it runnable first:

chmod +x Bibirble/Bibirble

If it won't start at all, this shows any library that's missing:

ldd ./Bibirble/Bibirble | grep "not found"

4. Add it to your app menu (optional)

This copies Bibirble into your home folder and adds a menu entry with its icon. It doesn't need sudo. Run these from the folder you unpacked into:

cd Bibirble
mkdir -p ~/.local/bin ~/.local/share/applications ~/.local/share/icons/hicolor/512x512/apps
cp Bibirble ~/.local/bin/ && cp bibirble.png ~/.local/share/icons/hicolor/512x512/apps/ && cp bibirble.desktop ~/.local/share/applications/

Bibirble should now be in your app menu, under Games or Education. If it doesn't show up, log out and back in.

To uninstall:

rm ~/.local/bin/Bibirble ~/.local/share/applications/bibirble.desktop ~/.local/share/icons/hicolor/512x512/apps/bibirble.png

Your Daily progress is saved in ~/.Bibirble. Delete that folder too if you want a completely clean slate.

Building from source instead

Use this for older Linux versions or ARM computers (like a Raspberry Pi). Install the build tools and libraries first.

Ubuntu, Mint, Debian:

sudo apt install build-essential cmake libwxgtk3.2-dev nlohmann-json3-dev

Fedora:

sudo dnf install gcc-c++ cmake wxGTK-devel json-devel

Arch:

sudo pacman -S --needed base-devel cmake wxwidgets-gtk3 nlohmann-json

Then build from the repository folder and run it:

./build.sh Release
./build/Bibirble
