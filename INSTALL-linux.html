Installing Bibirble on Linux

Bibirble for Linux is a single file with the verses and icon built in. It needs a 64-bit Linux with glibc 2.38 or newer (Ubuntu 24.04+, Mint 22+, Debian 13+ or Fedora 39+; check with ldd --version), plus GTK 3 and libSM, which most desktops already have. If one is missing, install it with sudo apt install libgtk-3-0 libsm6 (Ubuntu/Mint/Debian), sudo dnf install gtk3 libSM (Fedora) or sudo pacman -S --needed gtk3 libsm (Arch). To play, unpack it with tar xzf Bibirble-Linux-x86_64.tar.gz and run ./Bibirble/Bibirble. If it won't start, ldd ./Bibirble/Bibirble | grep "not found" shows what's missing. To add it to your app menu, copy Bibirble to ~/.local/bin/, bibirble.png to ~/.local/share/icons/hicolor/512x512/apps/ and bibirble.desktop to ~/.local/share/applications/. On older Linux versions or ARM computers, build from source instead: install build-essential cmake libwxgtk3.2-dev nlohmann-json3-dev, then run ./build.sh Release.
